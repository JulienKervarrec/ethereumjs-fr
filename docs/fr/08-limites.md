# 8. Limites et périmètre

Ce parcours couvre l’architecture EthereumJS, l’EVM, les transactions, les blocs, la chaîne, l’état, les tries, les preuves, les hardforks et la composition des packages.

Il ne constitue ni un audit ni une garantie de compatibilité universelle. Les licences sont à vérifier package par package ; le monorepo indique principalement MPL-2.0.

La lecture repose sur le README et la carte des packages. Aucune installation, compilation ou exécution de test n’a été effectuée. Consultez les tests du dépôt pour poursuivre.

Retour au [sommaire](README.md).
