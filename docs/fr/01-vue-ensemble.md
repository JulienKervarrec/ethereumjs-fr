# 1. Vue d’ensemble d’EthereumJS

EthereumJS est une pile TypeScript modulaire pour l’exécution Ethereum. Le monorepo sépare EVM, VM, transactions, blocs, état, tries, configuration de chaîne et primitives de codage.

Chaque package peut être utilisé seul ou composé avec les autres. Cette architecture rend les expériences de protocole plus lisibles et permet une utilisation dans Node.js ou le navigateur.
